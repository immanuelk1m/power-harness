# 휴리스틱 금지 규칙 (v1, 2026-10-14 사용자 지시 — 태양풍 하네스 v5와 같은 원칙)

historical 최고 레시피(P0420 계열)에는 사람이 손으로 정하거나 2025 평가창 sweep으로 고른 구조·표현 결정이 많다. 이 스킬은 **그런 휴리스틱을 새로 만들거나, 기존 휴리스틱의 값을 바꿔 보는 행을 제안하지 않는다.** 대신 그 자리를 데이터에서 학습하는 구성요소로 바꾸는 행은 권장한다.

## 금지 범주와 챔피언 계열의 실제 예

| 범주 | 챔피언 계열의 예(이미 레시피에 있음) | 새로 제안하면 안 되는 형태 |
|---|---|---|
| (a) 고정 창·시작일·patch 폭 | `train_from` 2022-01-01(19→36개월 sweep), 제공 baseline의 TRAIN_FROM 2023-06-01, ctx7 patch(±N시간, ctx3/5/9 비교) | "최근 N개월만 학습", "±N시간 주변 예보 평균", "N일 rolling 실적" 같은 창 상수 |
| (b) 입력 선택·임계값 | NWP round 17만 사용(10/17 중 선택), WA 6변수·WB 9변수 수동 선택, 결측·이상치 임계값 | 사람이 고른 변수 부분집합, 임계값으로 흐린 날·맑은 날을 나누는 것 |
| (c) 수동 구간 bin·테이블 보정 | hourbias: 그룹×시간 48칸 bias 표 + 축소 상수(bd100/bd400/sh1000/sh20000 sweep), smpclim: 시간대 SMP 기후값 고정 가중, smp 월별 가중 | 시간대·월·계절 bin을 사람이 정한 보정 표, 고정 가중 표, 축소·상한 상수 |
| (d) 수동 군집·분할 | `affine/clusters.json` 정적 위경도 군집, jes affine의 bin 수(nb2/4/6/8/12) | 위경도·용량으로 사람이 정한 군집 수·경계, 사이트 분할 규칙 |
| (e) 멤버·결합의 수동 선택 | ensemble/ensrel 멤버, fusion 가중, K=3 pattern experts | 손으로 고른 앙상블 멤버, 고정 가중·convex 결합, 고정 계수 branch |
| (f) 그룹 구성 탐색 상수 | composition v2의 min-cap 20,500kW 재탐색(규칙 하한 20,000kW에 사람이 둔 여유) | swap 탐색의 여유 상수·반복 수를 사람이 바꿔 보는 것 |

## 금지 형태
1. **새 휴리스틱 도입.** 위 범주에 해당하는 손으로 정한 창·시작일·patch 폭·변수 부분집합·임계값·bin·군집 수·가중·축소 상수를 새 변경으로 넣는 것.
2. **기존 휴리스틱 값 바꾸기.** 예: train_from 2022→2021, ctx7→ctx5, bd400→bd300, 48칸→96칸, 군집 K 변경, round 17→10. 몇 개 값을 놓고 sweep·검증 창(특히 2025 평가창)으로 고르는 것도 같은 금지다.
3. 위 두 가지를 다른 이름("adaptive window", "robust bias table" 등)으로 바꿔 쓴 것도 포함한다. 값이 학습 중 컷오프 이전 데이터로 정해지는지로 판단한다.

## 허용 형태
1. **학습형 대체 (권장).** 챔피언의 휴리스틱 하나를, 모델이 학습 중 컷오프 이전 데이터로 정하는 구성요소로 바꾼다. INCREMENT의 단일 변경으로 낼 수 있다.
   - (a) → 표본별 시간 가중을 학습(예: 공변량 이동 추정에 기반한 importance weight), 길이 제한 없는 이력 위의 학습형 temporal encoder.
   - (b) → round 10/17과 WA/WB 전 변수를 넣고 모델이 선택(학습형 gating·attention·정규화 경로).
   - (c) → 시간·그룹·기상 상태를 입력으로 받는 학습형 보정 head(컷오프 이전 OOF에서 학습), 정산 손실(SMP·k 가중 L1)을 직접 최소화하는 학습.
   - (d) → 사이트 임베딩·학습형 그래프로 유사 사이트를 학습.
   - (e) → origin 상태를 입력으로 받는 학습형 stacking/gating(컷오프 이전 OOF에서 학습).
   - (f) → 그룹 구성을 컷오프 이전 OOF 위의 최적화 문제로 풀되 제약(≥20,000kW)만 규칙에서 가져오는 것.
   - 학습형 대체의 하이퍼파라미터(층 수, 학습률 등)는 일반 모델 하이퍼파라미터로 보고 허용한다. 단 구조·표현 결정이 다시 사람 손으로 돌아가면 안 된다.
2. **문헌에 정의된 표준 물리량.** 태양 천정각·고도(NOAA/SPA), 대기권 밖 일사, 청천 일사(Ineichen–Perez, Haurwitz 등), 청명 지수(clearness index), 경사면 일사(Perez 모델), PV 셀 온도(Faiman, NOCT/Sandia 모델), 온도 계수에 따른 출력 보정. `[휴리스틱 검사]`에 정의 출처를 인용한다. 계산에 상수가 필요하면 그 정의가 정한 값을 쓰거나 학습 파라미터로 둔다.
3. **원시 입력을 학습형 표현으로 직접 넣는 것.** 예: 발행분 NWP 전체 시퀀스, 위성 영상(사용자 예외 범위).
4. 이미 챔피언 레시피에 있는 휴리스틱을 **그대로 두는 것**은 위반이 아니다. 단일 변경 행은 기준 레시피를 바꾸지 않는다. 대회 규칙이 정한 값(k=3 시간대 11–15시, ≥20,000kW, 발행 17:00)은 휴리스틱이 아니다.

## 행 작성 전 자가 점검 (모두 "아니오"이거나 출처가 있어야 쓴다)
1. 이 변경에 사람이 값을 정한 창·시작일·patch 폭·임계값·bin·군집 수·가중·축소 상수·변수 부분집합이 새로 들어가거나 바뀌는가?
2. 고차원 입력(전체 NWP 시퀀스·위성 영상·사이트 집합)을 사람이 고른 스칼라나 구간 요약으로 줄이는가?
3. 들어가는 물리량이 문헌 정의가 아니라 이 행을 위해 만든 공식인가?

하나라도 "예"면 그 부분을 학습형 대체로 바꾸거나 후보를 버린다. 결과는 행의 `[휴리스틱 검사]` 칸에 적는다.
